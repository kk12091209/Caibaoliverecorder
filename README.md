## 可以做什么

安装占用、下载体积与 SHA-256 见对应 Release 的体积报告和校验文件，录像、导出视频和预处理缓存另计。这是磁盘占用，不是运行内存上限。完整更新记录见 [CHANGELOG](CHANGELOG.md)。

- **监控直播间并自动录制**：添加 B 站或抖音房间号、直播链接，自动识别平台，等待开播；支持停止监控和移除房间。
- **边录边回看、选段**：内部按小段写入，界面呈现连续时间轴，不需要手动管理分片。
- **两种时间定位**：按视频时间点定位，或按北京时间选择录制日期与时刻，支持跨午夜。
- **波形与弹幕密度**：进度条内显示音频波形，下方显示有效弹幕密度；可缩放和横向浏览长录像。
- **弹幕编辑与限流**：搜索、跟随播放位置、手动排除消息；内置过滤礼物、整条表情占位消息，以及能识别的福袋 / 天选抽奖口令。每个房间的每秒上限可调 1～50；30 字及以上过滤，10 秒内同文达到 5 条只留一条，少量重复保留。
- **三种导出模式**：纯净版、弹幕版、纯净 + 弹幕双文件。Windows v0.2.1 / Mac v0.2.1 每个勾选片段创建独立任务，按列表顺序逐个导出，也能导出完整素材。
- **录完自动预处理**：素材正常结束并整理完成后，加入弹幕预处理队列。需要成片时手动导出；兼容的完整纯净版直接复制音视频码流，不重新编码。
- **复用弹幕缓存**：预览、选段和波形分析时预处理继续；录制、正式导出和素材整理时暂缓。导出复用已完成且仍有效的块，缺口再处理。
- **任务管理**：右键取消进行中的导出，或二次确认后删除某个导出任务及其成片；编码完成但保存失败可重试保存。
- **适配较小窗口**：侧栏可收起，时间轴和编辑控件会随可用空间调整。

## 快速开始

1. 按上面的下载表选择系统。Mac 将应用拖入“应用程序”；Windows 运行 `setup.exe` 安装，或先**完整解压**便携包。
2. Mac 从“应用程序”打开“菜播·录包机”；Windows 打开 `录播机.exe`。
3. 添加 B 站或抖音直播链接、纯数字房间号。只有一个匹配时直接添加；两边同号时弹窗显示主播名、平台和开播状态，选择后确认添加。取消不会启用监控；平台暂时无法查询时可重试或使用完整链接。未开播时保持监控；“停止”会停止该房间的监控或录制，重开软件仍保持停止，“开始”才重新启用。
4. 在左侧选择录像素材，播放回看，通过波形和弹幕密度寻找片段。起终点旁实时显示片段时长，拖动标记可微调。设置起终点后点击“添加选段”。
5. 勾选需要的片段，点击“导出选段”，选择纯净版、弹幕版或双文件；Windows v0.2.1 / Mac v0.2.1 每个片段分别生成一个导出任务，按顺序逐个处理；每个任务生成所选版本的视频。
6. 录制结束并整理完成后，右键已完成的素材 →“导出完整素材”，选择纯净版、弹幕版或双文件。
7. 在导出任务中点击“打开文件夹”查看成片。

只有手动导出才会生成成片；重复导出使用新的文件名，不覆盖已有视频。预处理默认开启，可在设置中关闭；失败会显示原因，不会因此删除原片。首版不额外建立纯净视频缓存，以控制空间占用。

启动地址由软件自动分配，无需设置端口；重复打开同一份软件会回到已有窗口。**点击关闭窗口时可选择“退出”或“后台运行”，勾选“不再提示”可记住所选操作。** 在设置的“关闭窗口时”中可修改默认操作或恢复每次询问。后台运行时任务继续，Windows 双击托盘图标返回，Mac 从菜单栏图标或 Dock 返回。空闲或仅监控时直接退出；有录制、导出任务时先确认，确认后停止任务；Mac 等待后台完全停止再关闭应用，期间会显示正在退出。下次启动自动恢复监控、重新开始录制，并继续未完成的导出；关闭期间的直播内容无法补录。已编码的视频会继续保存，无需重编。停止某个房间请使用它的“停止”按钮。首次使用建议先录制并导出一小段，确认声音、画面和路径符合预期。

## 视频保存在哪里

设置中可以更改导出根目录。**Mac** 默认导出到 `~/Movies/菜播·录包机`（个人目录的“影片”），内部录像、弹幕和编辑数据位于 `~/Library/Application Support/Caibo/data`。替换或删除 `.app` 不会清理这些数据。

**Windows** 默认位置在安装或解压目录旁：

```text
菜播·录包机/
├─ 录播机.exe
├─ 使用说明.txt
├─ 程序组件/                    运行依赖和内部数据
└─ 导出视频默认路径/
   ├─ 完整素材/
   │  └─ 20260928/
   │     ├─ 202609282130-2140.mp4
   │     └─ 【弹幕版】202609282130-2140.mp4
   └─ 导出片段/
      └─ 20260928/
         └─ 202609282133-2135/
            └─ 【弹幕版】202609282133-2135.mp4
```

命名使用素材的**录制时间（Asia/Shanghai）**，而非点击导出的时间。整场跨天时按开始日期归档，例如 `202609282350-202609290010.mp4`。同名文件增加 `_2`、`_3` 等后缀。导出文件夹最终只保留所选版本的 MP4，弹幕已经烧录到弹幕版的画面中，普通播放器即可观看。

## 磁盘空间与删除

Windows 内部数据位于 `程序组件/live-editor/data`；Mac 路径见上一节。录制时会保存原始 FLV / XML 与临时分片；结束后，在核对通过且没有读取者占用时释放重复分片。核对不通过则保留必要数据，避免丢失素材。弹幕预处理还会使用额外缓存，预算为 20 GiB，并在处理前保留至少 2 GiB 可用空间；这不是整个项目的磁盘上限。

| 操作 | 清理什么 | 保留什么 |
| --- | --- | --- |
| 右键录像素材 → 删除素材 | 本程序管理的原片、弹幕、内部片段、该素材的预处理缓存和编辑记录 | 已导出的纯净版、弹幕版 / 双文件 |
| 右键导出任务 → 删除导出任务 | 该任务对应的成片和任务记录 | 原始录像与编辑记录、其他任务的成片 |
| Windows 卸载软件 | 整个安装目录、快捷方式和卸载记录，包括目录内全部录像、导出视频、缓存、设置和遗留文件 | 安装目录外的文件 |
| Mac 将 `.app` 移到废纸篓 | 应用程序本身 | 录像、导出视频、缓存和设置 |
| Mac 菜单「菜播·录包机 → 完整卸载…」 | 停止后台后，将当前应用及内部录像、弹幕、设置、缓存移到废纸篓；重新安装从干净状态开始 | 数据目录之外的导出视频；废纸篓中的文件仍可恢复 |

两种删除都需要二次确认，确认后永久清理，没有回收站。录制、整理、导出或有待保存成片的素材不能删除。素材删除受理后关闭确认框，在后台继续清理；可点击「素材清理进度」查看阶段和数量。文件占用或超时会保留清理记录，等待占用释放后重试；仍未完成时可以手动重试，后台空闲时也会继续清理。只有实际清理完成才提示已清理完成。成片已被手动删除时仍可移除失效任务记录。

若希望释放一场录像的全部空间，需要分别删除录像素材和不再需要的导出任务。不要手动清空内部 `data`、`chunks` 或 `temp`：其中可能有正在使用的数据或编码完成但尚未保存的唯一成片。

## 画质、帧率和导出速度

- 录制保存平台提供的原始流，不是录屏。B 站与抖音优先选取匿名访问可用的最高兼容 H.264/AAC 流；没有账号登录界面，也不承诺所有房间都能取得平台最高档画质。
- 满足格式条件的**整场纯净版**使用码流复制，只更换封装，不改变画质；不兼容时使用现有编码回退。精确切片可能需要重新编码。
- **弹幕版固定输出 60 帧**，使用原分辨率；软件编码 CRF 为 20，硬件编码使用对应的质量参数。30 帧源视频保留原有动作帧，重复帧用于承载更平滑移动的弹幕，不做运动插帧。
- Windows 自动探测 NVIDIA、AMD、Intel 硬件编码能力，Mac 使用 Apple VideoToolbox；不可用时回退软件编码。具体速度取决于显卡、CPU、源视频、弹幕密度、磁盘和缓存命中情况。
- 预处理无需全部完成才可导出。已覆盖的整块直接复用，缺失、失效或需要精确边界处理的部分仍会编码，不保证任意设备都能在十分钟内导出两小时素材。

## 更新与问题反馈

**支持应用内自动更新。** 默认每天检查本仓库最新正式 Release，也可在“设置 → 软件更新”手动检查。点击“更新并重启”后下载并核对大小及 SHA-256；下载期间可以继续工作，安装会等待录制、导出和素材处理结束。Mac 暂存并验证新应用后替换，失败时恢复原程序；Windows 使用原安装目录静默升级。软件安全退出后自动打开新版，录像、导出视频和设置保留，无需先卸载。

Mac 请先把应用拖到“应用程序”或其他自己可写的目录；从只读 DMG 启动不能自动替换。Windows 请使用安装版；便携版需要先运行安装包安装一次。没有“更新并重启”按钮的旧版需要手动下载并覆盖安装一次，此后即可在应用内更新。设置中只显示产品版本号；0.1.7 起，新的更新使用递增的版本号。

更新缓存保存在内部数据目录的 `updates` 文件夹，可在设置中清理下载的包；失败诊断记录在对应的 `apply-*` 目录。软件更新不会删除录像。字体导入支持 32 MB 以内的 TTF、OTF 文件，不需要安装系统字体；请选择包含中文字形、允许相应用途的字体。在「设置 → 调整弹幕样式」中导入并点击「保存样式」后应用于预览和新建的弹幕导出，原始弹幕文件、已完成的视频和已经创建的任务不改写。
提交 [Issue](https://github.com/kk12091209/Caibaoliverecorder/issues) 时，请附软件版本、操作系统版本、芯片 / 显卡、复现步骤和具体报错。分享日志或截图前移除个人路径、Cookie、账号信息和不希望公开的直播内容。

**日志位置：** 在“设置 → 点击查看日志文件”中打开日志目录。`logs/日期.txt` 是每天的运行记录，按北京时间记录打开、关闭、监控、录制状态和错误，最多 512 KiB，保留最近 30 个日历日。Mac 启动失败时，可在失败页面点击“打开日志文件夹”，查看数据目录中的 `desktop-startup.log`（重试操作、连接结果及进程退出）和 `desktop-backend.log`（后台启动阶段及错误）。`bilirec日期.txt` 是 B 站录制核心日志，不能替代这两份启动日志。连接期间会显示正在重连及等待时间；后台恢复后自动加载界面，保留录像与设置。

**旧数据异常兜底：** 工作台先打开，再恢复历史导出任务。损坏的设置自动恢复默认，异常的任务或剪辑记录单独隔离，原记录保留在本机；不会因为一条坏记录反复卡在启动页面。素材索引无法读取时启用独立安全数据区，原索引、原始录像和弹幕保留，界面显示提示及「查看旧录像」。新录像和设置写入安全数据区，后续启动继续使用；无法保证恢复已损坏索引中的历史剪辑记录。录制核心配置损坏时先备份再恢复，录像保留，并按已保存的主播启停开关恢复；B站和抖音连接状态分别显示。磁盘满、无权限或已有后台占用不会触发清空数据。启动失败页面和 Mac 菜单也能直接打开原始录像文件夹，无需后台连接。

**Mac 完整卸载：** 从应用程序文件夹打开软件，选择菜单「菜播·录包机 → 完整卸载…」，确认后停止后台并把应用与内部数据移到废纸篓。正常覆盖安装或应用内升级会保留数据；仅拖走 `.app` 无法可靠区分卸载和更换新版，所以不会自动删除录像。完整卸载入口无需网页正常加载，仍会核实后台已退出；当前应用位于只读 DMG 或后台尚未停止时不会移动数据。

**Mac 自动修复：** 后台持续不响应时，先正常停止，再根据进程启动时间、可执行路径和子进程归属强制回收本应用组件，每轮异常最多重启两次，包含初次启动共最多启动三次；立即崩溃和持续失败都会暂停自动重启，显示原因与重试入口。运行组件或界面文件缺失时，原生启动器从本项目 GitHub 当前版本的完整发布包下载修复，校验 SHA-256、大小、应用身份、版本与签名后替换并重启；即使 Node 缺失也可执行。录像、设置和日志保留。自动下载十分钟内最多尝试一次，修复期间显示进度，失败页面显示原因和“重试”。需从可写安装目录运行；网络、磁盘空间、目录权限或系统安全拦截无法修复时会停止自动替换。旧应用备份在新界面就绪后清理，替换或启动命令失败会回退。

Windows 安装版可从开始菜单、Windows“已安装的应用”，或安装目录里的“卸载菜播·录包机”卸载。**v0.1.3 起，卸载永久删除整个安装目录，包括内部录像、弹幕、编辑数据、预处理缓存、默认导出视频和其他遗留文件。需要保留的文件请先移到安装目录之外。** 设置为安装目录外的导出路径不会被清空。正在录制或处理任务时仍会拒绝安装或卸载，等待完成或在软件内主动停止后重试。升级到原目录会保留数据，无需先卸载。便携版不创建卸载记录，退出后删除解压目录即可。
