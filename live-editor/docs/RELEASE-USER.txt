菜播·录包机 · Windows 版 0.1.3

开始使用
1. setup.exe 是中文安装向导；ZIP 是便携包，需先完整解压。
2. 从开始菜单或安装/解压目录打开“录播机.exe”。请保留旁边的“程序组件”。
3. 添加 B 站或抖音房间号、直播链接，自动识别平台。同号两边都有主播时，选择后确认添加。未开播时保持监控；停止状态会保存，重开仍需点击开始重新启用。
4. 选择录像素材，在时间轴回看、设置起终点、添加选段；勾选后导出。

自动处理与导出
录制结束、素材整理完成后，自动加入弹幕预处理队列。
只有用户手动导出才会生成成片，不额外建立纯净视频缓存。
兼容的完整纯净版复制原始音视频码流，不重新编码；不兼容时使用编码回退。
预览、选段和波形分析时预处理继续；录制、正式导出和素材整理时暂缓。
可在设置中关闭自动预处理，或对单份素材暂停、继续。
预处理不在导出文件夹自动生成成片。
要导出整场视频，右键已完成素材 → 导出完整素材。
整场和选段均提供纯净版、弹幕版、双文件三种模式，默认双文件。
弹幕版为 60 帧；30 帧视频不做运动插帧。已有有效缓存会复用。
显卡编码自动探测，不可用时回退 CPU。导出速度随设备和缓存情况变化。

视频在哪里
默认在程序旁边的“导出视频默认路径”，设置中可修改根目录。
  完整素材/日期/视频.mp4
  导出片段/日期/起止时间/视频.mp4
按北京时间的录制时间命名，弹幕版以“【弹幕版】”开头，同名自动加序号。
导出文件夹只保留所选 MP4，普通播放器即可观看。
编码完成但保存失败可重试保存或更换保存位置，无需重新编码。

编辑
起点前可切换视频时间 / 录制时间；后者按北京时间定位，支持跨午夜。
进度条内是音频波形，下方是弹幕密度，可缩放和横向拖动浏览。
起点、终点标记可拖动；按住 Shift 小幅拖动，聚焦标记后方向键逐帧微调。
添加选段后仅保留选段色块，起点和终点标记收起；删除选段后色块消失。
起终点旁实时显示当前片段时长，精确到毫秒。
礼物、整条表情占位消息和明确标记的抽奖口令自动过滤。
30 字及以上的弹幕过滤；10 秒内同文重复达到 5 条时只保留一条。
设置中可调整每个直播间每秒弹幕上限，范围 1–50 条。
可手动排除弹幕。素材、弹幕侧栏可收起，适配小窗口。

磁盘与删除
内部原片、弹幕、数据库和处理缓存位于程序组件/live-editor/data。
正常结束并核对通过后释放重复分片；不通过时保留必要数据。
预处理缓存预算 20 GiB，并保留至少 2 GiB 可用空间；不是整个目录的空间上限。
右键删除录像素材：清理内部原片、分片、缓存和编辑记录，保留已经导出的 MP4。
右键删除导出任务：删除该任务的成片和记录，保留原始素材及其他任务成片。
两者都需二次确认，永久删除，不设回收站；清理失败可重试。
进行中的导出可右键取消。录制、整理、导出或有待保存成片的素材不能删除。
不要手动清空内部 data 或 temp，可能包含正在使用的数据或待保存的唯一成片。

系统与更新
支持 Windows 10 / 11 x64。需要 .NET Framework 4.7.2+ 与 WebView2 Evergreen。
WebView2 官方地址：https://developer.microsoft.com/microsoft-edge/webview2/
Node、FFmpeg、录制核心已包含，无需开发 SDK。系统组件缺少时需另行安装。
启动地址自动分配，不需要设置端口；重复打开会返回已有窗口。
点击关闭窗口可选择退出软件或缩小到后台；勾选“不再提示”可记住所选操作。
在设置的“关闭窗口时”中可修改默认操作，或恢复每次询问。空闲或仅监控时直接退出。
录制或导出中退出需确认；确认后停止任务，下次启动自动恢复。关闭期间的直播内容无法补录。
后台版本切换会等待任务结束；软件自动处理连接和进程，无需手动结束后台。
长任务期间请勿让电脑休眠。首版没有自动下载更新；到项目 Releases 下载新版。
更新前从托盘退出软件，保留旧数据；不要在录制中覆盖程序组件。

安装与卸载
安装向导支持选择目录和桌面快捷方式。升级时选择原安装目录，保留内部数据与导出视频。
可从开始菜单、Windows 已安装的应用，或程序目录里的“卸载菜播·录包机”卸载。
卸载程序在 程序组件/卸载 中；永久删除整个安装目录，包括录像、导出视频、缓存和设置。
需要保留的文件请先移到安装目录之外。安装目录外的导出路径不会被清空。
正在录制、导出、整理或预处理时，安装/卸载会拒绝继续；请等待完成或在软件内主动停止。
便携版没有卸载记录；先退出软件，再删除解压目录。需要保留的文件请先移出。
