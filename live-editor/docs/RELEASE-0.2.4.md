# v0.2.4 — 预览切换与自动释放修复

Windows 与 Mac 同步更新至 0.2.4。

- 同一窗口只运行一个预览。连续定位、逐帧查看或切换素材时，先取消旧预览并等待退出，再加载最后选中的位置。
- 修复旧任务尚在退出时，被误计为多个预览窗口，导致单窗口出现“同时预览数量已达上限”的问题；刷新页面遇到旧任务收尾时也会自动等待。
- 取消选中、切换素材及关闭页面时主动释放该窗口的预览；迟到的旧请求或取消指令不会重新启动旧画面，也不会停止新的预览。
- 多窗口的预览互相独立，继续保留真正同时播放多个窗口时的资源上限。删除素材与退出程序会同时取消排队中的预览；释放异常超时会给出明确提示。
- 保持现有录制、选段、导出和双渠道内置更新流程。

## 安装与升级

- Windows 10 / 11 x64：中文安装包及 ZIP / 7z 便携包；安装版支持内置更新，便携版需先安装一次才能自动覆盖更新。
- Mac：Apple Silicon、macOS 14+，提供 DMG 与 ZIP；沿用 ad-hoc 签名，尚未完成 Apple 公证，暂不支持 Intel Mac。
- 在软件内选择更新并重启，等待录制和导出结束后更新，保留录像和设置；也可从官网下载并覆盖安装。
