Windows 新版已包含逐段独立导出修复：**选中 3 个片段，生成 3 个独立任务，按列表顺序依次完成**。每个任务有自己的进度与成片；双文件模式下，每段各输出纯净版、弹幕版两个 MP4。

## 下载与升级

- **推荐：BiliLiveEditor-0.1.5-win-x64-setup.exe**，中文安装向导。
- `BiliLiveEditor-0.1.5-win-x64.zip` / `.7z`：便携版，完整解压后运行 `录播机.exe`。
- 支持 Windows 10 / 11 x64，需要 .NET Framework 4.7.2+ 与 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。Node、FFmpeg 和录制核心已包含。
- **升级无需先卸载。** 退出软件，运行新版安装包，选择原安装目录；升级保留录像、设置和导出视频。v0.1.3 起卸载会清理整个安装目录，需保留的文件请先备份或移到目录之外。
- 安装程序未使用付费代码签名证书；Windows 可能显示未知发布者或信誉提示，请核对来自本仓库及 SHA-256。

## 验证与源码

Windows 云端完成共用编辑器回归、实际三段顺序导出、录制核心测试与启动/复用/退出、ZIP/7z 完整性，以及安装、保留数据升级、忙时拒绝维护和完整卸载验证。实际显卡硬件加速、WebView2 窗口与真实直播仍建议在用户 Windows 设备上验收。

`windows-build.json` 记录源码提交与检查结果；`SHA256SUMS.txt` 提供附件校验值；大小报告区分安装包下载体积与安装占用。安装包保持低于 100,000,000 字节的既有门槛。

`Caibo-0.1.5-source.zip` 是对应源码，普通用户无需下载。未改动的 Node 24.12.0 与 FFmpeg 8.1.2 复用经固定哈希校验的 v0.1.3 组件，界面、Windows 桌面壳及录制核心均重新构建；组件许可、FFmpeg 构建配置与依赖源码来源随包保留。

录制核心沿用既有依赖；NuGet 仍报告 AutoMapper 13.0.1 和 AngleSharp 0.17.1 的上游依赖告警，本次没有进行跨大版本升级。
