# v0.1.8 — 每日日志与持续运行改进

Windows 与 Mac 同步更新至 0.1.8。

- 设置新增「点击查看日志文件」，打开本机日志目录；按北京时间保存每日 TXT，使用时即时写入，跨日／下次启动补充汇总。
- 记录打开与退出、用户录制开关、开播状态、录制核心断连与恢复、录像文件事件、素材处理／删除和导出错误。未知原因明确标注；强制结束只补记最后存活时间。
- TXT 每份最多 512 KiB，保留最近 30 个自然日；重复错误合并，认证信息与直播流链接隐藏，不记录弹幕正文。日志仅存本机，可把对应日期的 TXT 发给开发者协助排查。
- 修复抖音监控循环被异常打断，Windows 后台连接总等待限制为 60 秒；重连保留停止／自动录制设置。
- 两端在监控或处理任务时请求防止系统空闲休眠，并在唤醒后恢复检查。电脑关闭、合盖、手动／强制休眠期间无法录制或补录。

长时间行为采用代码检查和模拟日期、网络与磁盘失败的自动化测试验证，未进行连续多日的真机验收。

Mac 支持 Apple Silicon、macOS 14+，使用 ad-hoc 签名，尚未公证；Windows 安装版支持应用内更新。软件内只显示版本号。
