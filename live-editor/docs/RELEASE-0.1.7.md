# v0.1.7 — Windows / Mac 同步更新

- 界面启动或使用中持续无响应时自动恢复，无需先手动点击重置；保留录像、设置和后台任务。
- Mac 增加加载状态、界面文件检查和后台连接总超时，改善异常加载后永久白屏的问题；回收旧窗口的卡死页面进程。
- 更新设置、更新提醒和下载页面只显示版本号。以后小更新按 0.1.8、0.1.9 递增。
- 后台隐藏时避免误触发界面恢复；退出收尾完成后释放后台进程，Windows 安装与卸载等待本应用的运行时退出。
- 已有内置更新功能的 0.1.6 用户可以在设置中“更新并重启”。没有该按钮的旧版用户手动覆盖安装一次，无需先卸载。

Windows 提供中文安装包、ZIP / 7z 便携版；Mac 提供 Apple Silicon DMG 拖放安装包和 ZIP。Mac 要求 macOS 14 或更新，仍采用临时签名、未经过 Apple 公证。

恢复窗口期间可能需要重新选择正在预览的素材；已经保存的剪辑和后台任务保留。连续恢复失败时停止重试并显示提示，避免无限重启。完整校验和构建记录随发布附件提供。
