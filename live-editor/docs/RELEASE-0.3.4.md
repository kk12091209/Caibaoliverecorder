# v0.3.4 — 礼物记录与弹幕突出显示

Windows 与 Mac 同步更新至 0.3.4。

- 新增 B 站、抖音礼物记录和 B 站上舰标记，可按金额筛选、点击定位；礼物展示与导出默认关闭，分别控制。
- 礼物金额和最低门槛统一以人民币元显示；抖音按 10 抖币 = 1 元折算，保留平台原始价格。
- 开启“展示礼物”后，列表支持“仅显示礼物”，方便查找感谢礼物的时间点；不改变画面或导出设置。
- 弹幕列表支持右键筛选发送者，缺少完整身份时提示昵称近似匹配风险。
- 支持单条弹幕突出显示、1～3 倍字号、自选颜色及可选昵称前缀；预览和导出保持一致。
- 保留 0.3.3 的弹幕认证、断线重连及日志修复。

礼物记录从升级后的新录制开始生效，历史录像没有保存的礼物无法补回。部分礼物图标缺失时使用占位标识。
