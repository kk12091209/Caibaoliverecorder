# v0.2.7 — 录制断流恢复与后台性能优化

Windows 与 Mac 同步更新至 0.2.7。

- 优化 B 站录制中网络断流、写入停滞及音视频时间戳不再前进时的检测和重连。按房间恢复，避免单个房间的问题影响其他录制。
- 减少长关键帧间隔导致的数据积压，保留关键帧分段规则；录制统计只记录成功写入的数据。
- 录制异常时显示恢复状态。已确认缺失的录像区间在时间轴单独标记，定位到缺失处时跳至下一段可播放内容，避免误认为普通静音。
- 后台预处理改为按变化增量检查，分批处理历史任务，补充查询索引。大量历史素材下减少反复扫描和重复处理。
- 界面优先使用实时状态推送，连接异常时自动轮询兜底；减少已结束素材的重复刷新。

恢复速度仍受网络、直播平台和存储设备影响；断流期间未收到的画面无法补录，不保证零丢失。旧录像中已经缺失的内容不会凭空恢复。

## 安装与升级

- Windows 10 / 11 x64：中文安装包及 ZIP / 7z 便携包；安装版支持内置更新。
- Mac：Apple Silicon、macOS 14+，提供 DMG 与 ZIP；沿用 ad-hoc 签名，尚未完成 Apple 公证，暂不支持 Intel Mac。
- 软件内选择更新并重启，等待录制和导出结束后更新，保留录像和设置；也可从官网下载并覆盖安装。
