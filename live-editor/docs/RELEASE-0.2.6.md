# v0.2.6 — 连麦名牌与语音头像

Windows 与 Mac 同步更新至 0.2.6。

- B 站与抖音支持的连麦 / PK 画面，按平台提供的分区在对应人物右下角显示昵称；没有昵称时显示可确认的用户 ID 或连麦编号。
- 抖音普通观众上麦支持主播和观众身份显示。右下角悬浮语音麦位补充真实抖音头像、半透明背景和昵称；开启摄像头时恢复视频，换位、下麦按录像时间同步。
- 头像随素材保存到本地，预览、纯净版、弹幕版、双文件和预处理导出使用相同身份信息。关闭弹幕预览也保留连麦信息；原始录像不改写。
- 支持抖音搜索页、分类页中带有明确 `live_web_rid` 的直播链接。

当前支持 B 站明确分区、抖音双人 / 多人 PK 及普通观众悬浮麦位。未知布局不猜测坐标；旧抖音素材未保存当时的名单或头像时，不会拿当前直播名单补猜历史人物。头像临时获取失败不影响录制。

## 安装与升级

- Windows 10 / 11 x64：中文安装包及 ZIP / 7z 便携包；安装版支持内置更新。
- Mac：Apple Silicon、macOS 14+，提供 DMG 与 ZIP；沿用 ad-hoc 签名，尚未完成 Apple 公证，暂不支持 Intel Mac。
- 软件内选择更新并重启，等待录制和导出结束后更新，保留录像和设置；也可从官网下载并覆盖安装。
