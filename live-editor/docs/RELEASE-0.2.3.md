# v0.2.3 — 双渠道内置更新与菜包宇宙入口

Windows 与 Mac 同步更新至 0.2.3。

- 内置更新优先通过菜包宇宙检查版本和下载更新；主渠道连接失败或超时后，自动改用 GitHub 备用渠道。
- 下载阶段同样支持自动切换：主渠道文件不可用、下载中断或校验失败时，从 GitHub 获取同版本、同校验值的更新文件。用户主动取消会停止，不继续备用下载。
- 菜包渠道使用带发布签名的更新清单，并继续核对版本、系统架构、文件大小和 SHA-256。
- 在软件内点击“更新并重启”，后台完成下载、校验与更新。等待录制、导出等任务结束，保留录像和设置，无需手动卸载重装。
- 软件左侧署名下新增“菜包宇宙：www.caibao.media”，点击后通过系统浏览器打开官网。

## 安装与升级

- Windows 10 / 11 x64：中文安装包及 ZIP / 7z 便携包；安装版可直接使用内置更新，便携版仍需先安装一次才能自动覆盖更新。
- Mac：Apple Silicon、macOS 14+，提供 DMG 与 ZIP；沿用 ad-hoc 签名，尚未完成 Apple 公证，暂不支持 Intel Mac。
- 0.2.2 及更早版本的更新源仍是 GitHub。可通过原有内置更新升级至 0.2.3；网络不便时从官网覆盖安装一次，此后使用双渠道更新。

官网：https://www.caibao.media/

两端使用同一源码提交构建。安装包校验值及验证范围见发布附件中的构建记录。
完整对应源码（含精确子模块和 Mac 许可文件）：https://github.com/kk12091209/Caibaoliverecorder/releases/download/v0.2.3/Caibo-0.2.3-complete-source.zip
