# v0.3.8 — 录制稳定性与剪辑体验优化

Windows 与 Mac 同步更新至 0.3.8。

- 改进异常录制恢复，重新获取直播地址时暂时避开最近失败的线路；更清楚地区分网络读取、文件写入和画面时间停滞，保留已录内容，恢复时遇到下播不再自动重启录制。
- 优化弹幕连接重试与日志：常规连接信息减少刷屏，重复故障合并记录，重要异常继续保留；弹幕连接失败不再连带阻塞正常的房间状态与直播地址查询。
- 优化长场次弹幕列表，按需加载并减少页面渲染；取消跟随后可浏览全场，新增竖向时间导航。跟随播放时展示当前位置前后各一分钟的记录，改善拖动后回弹的问题。
- 优化局部时间轴的播放跟随，支持拖动到边缘时自动平移；减少预览和时间轴重复查询，精简重复说明文字，保留必要错误提示。
- 移除预处理缓存的固定容量上限，默认累计达到 50 GiB 时提醒。点击“已知晓”后本轮不再重复；清理到提醒值以下后，再次达到时重新提醒。提醒大小可调整，仍保留磁盘实际可用空间检查。
- 支持清理可重建缓存，保留原始录像、导出文件与使用中的缓存；更明确地显示磁盘空间不足或空间查询失败的原因。

网络或直播平台断流期间仍可能出现短暂空档，无法补录平台未提供的内容。本次不调整直播源画质等级与导出码率。

Mac 包适用于 Apple Silicon、macOS 14 或更新版本，沿用临时签名，未经过 Apple 公证。Windows 需要 .NET Framework 4.7.2+ 与 WebView2。
