# v0.2.9 — 录制样式、Cookie 管理与导出优化

Windows 与 Mac 同步更新至 0.2.9。

- 设置中的“录制样式”集中管理独立摄像头与预览时间戳。摄像头默认左下角，时间戳默认左上角，均可自行选择位置。
- 增加三种透明底时间戳样式。时间戳仅用于本地预览，不写入原始录像或导出视频。
- 适配 B 站与抖音的独立摄像头布局，补充 B 站视频连麦的参与者名称展示。
- 增加可选的本地 Cookie 管理：两平台分别填写和更换，保存后不可查看旧值；Mac 使用钥匙串与 AES-GCM，Windows 使用当前用户 DPAPI。Cookie 不上传到菜包网站，不随安装包提供。
- 有效登录态可改善 B 站新弹幕的完整昵称获取，并可能开放更高画质。实测部分 B 站直播从 720p/30 帧提升到 1080p/60 帧；实际取决于直播源及平台权限。抖音无需账号 Cookie 即可获取完整弹幕昵称，本次样本登录后画质未额外提升。
- 优化未经预处理时的导出调度及资源使用，复用已完成的处理结果；录制时自动提前处理仍默认关闭。
- 合并重复的画面定位、实时布局、设置快照和媒体处理逻辑，保持既有样式与操作方式。

本版不提供“关注用户本人未开播时，自动发现其在其他直播间连麦并录制”的功能。

## 安装与升级

- Windows 10 / 11 x64：中文安装包及 ZIP / 7z 便携包；安装版支持内置更新。
- Mac：Apple Silicon、macOS 14+，提供 DMG 与 ZIP。沿用 ad-hoc 签名，尚未完成 Apple 公证，暂不支持 Intel Mac。
- 内置更新或覆盖安装保留录像、导出视频和设置。Cookie 为可选项，不要求用户填写；各平台教程在管理弹窗内展开。
