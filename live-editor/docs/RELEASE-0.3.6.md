# v0.3.6 — 统一主播监控与连麦跟录

Windows 与 Mac 同步更新至 0.3.6。

- 统一“监控主播”入口，支持 B 站直播间、抖音直播间与抖音名片分享内容。
- 抖音按主播身份自动跟随本人直播与连麦，确认退出后结束该段，重连或换房后继续监控；录像素材保留实际房间名称及直播／连麦标记。
- 精简监控卡片，后台保留参与记录，录像统一在素材区查看。
- 优化抖音连麦名称和主屏识别，补充弹幕连接状态与恢复处理。
- 加固本机界面、媒体与配置访问保护，限制异常直播数据的解析资源，并统一主备更新渠道的签名验证。

连麦发现受抖音公开信息与网络状态影响，采用轮询和退出确认，不能补录发现之前的画面。已验证本地状态切换与模拟重连；真实平台行为仍可能随上游调整。

Mac 包适用于 Apple Silicon、macOS 14 或更新版本，沿用临时签名，未经过 Apple 公证。Windows 需要 .NET Framework 4.7.2+ 与 WebView2。
