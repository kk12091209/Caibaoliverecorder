# v0.2.5 — 自由调整弹幕展示区域

Windows 与 Mac 同步更新至 0.2.5。

- 在「设置 → 调整弹幕样式」中框选弹幕展示区域：拖动上下细白横条调整高度，按住框内上下移动位置。宽度固定全屏，高度支持画面的三分之一至全屏，并可一键恢复全屏。
- 调整区域后自动更新静态预览，新增「播放滚动预览」，可直接查看当前区域内的滚动效果。
- 缩小区域时保留弹幕条数与字号，重新计算可用轨道和避让位置，让弹幕更集中；极高密度或大字号时仍可能重叠。
- 展示区域与其他样式一起保存，应用于播放预览和新建导出。旧设置默认全屏，已创建的导出任务保留原设置。
- 上下抓手采用简洁白色横条，悬停时突出显示，支持鼠标、触屏拖动和方向键微调。

## 安装与升级

- Windows 10 / 11 x64：中文安装包及 ZIP / 7z 便携包；安装版支持内置更新，便携版需先安装一次才能自动覆盖更新。
- Mac：Apple Silicon、macOS 14+，提供 DMG 与 ZIP；沿用 ad-hoc 签名，尚未完成 Apple 公证，暂不支持 Intel Mac。
- 在软件内选择更新并重启，等待录制和导出结束后更新，保留录像和设置；也可从官网下载并覆盖安装。
