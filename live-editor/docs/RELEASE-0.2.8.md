# v0.2.8 — 导出性能、分块恢复与预览时间戳

Windows 与 Mac 同步更新至 0.2.8。

- 优化预处理与导出复用，减少重复解码和编码；符合条件的纯净版复制原始码流。
- 长素材导出按块保存处理进度，失败后复用已验证的完成块，减少整段重做。
- 新增录制时提前处理选项，默认关闭；按资源与录制健康状态安排，优先保证录制。
- 优化密集弹幕排版与预览绘制，保留字号、显示范围和弹幕条数。
- 新增预览时间戳，默认关闭；在画面左上角显示录制时间，日期与时间采用相同样式，导出始终不包含时间戳。
- 启动后自动检查新版本，弹窗展示版本与更新内容，支持立即更新、关闭及仅屏蔽当前版本提醒。
- 修复暂停预览后连续定位或切换素材时，旧输出流可能未及时释放的问题。

## 使用说明

时间戳在“设置 → 录制设置”开启，使用北京时间；断流重连后依据各片段的实际录制时间显示。它只辅助本地预览，不写入原始录像、纯净版或弹幕版，也没有导出开关。

更新弹窗勾选“下次版本更新再提示”后关闭，会记住当前版本；之后出现新版本才再次弹窗。仍可在设置底部的软件更新中主动更新。点击“立即更新”后下载并校验安装包，等待录制、导出或素材处理完成后安装，不强行中断任务。

“录制时自动提前处理”默认关闭，需要时在设置中开启。实际处理速度受设备、分辨率、弹幕密度、磁盘和负载影响；分块恢复只能复用已完成并通过校验的内容，断流期间未收到的画面无法补录。

## 安装与升级

- Windows 10 / 11 x64：中文安装包及 ZIP / 7z 便携包；安装版支持内置更新。
- Mac：Apple Silicon、macOS 14+，提供 DMG 与 ZIP；沿用 ad-hoc 签名，尚未完成 Apple 公证，暂不支持 Intel Mac。
- 内置更新或覆盖安装保留录像、导出视频和设置。
