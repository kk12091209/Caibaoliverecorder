# v0.2.0 — 弹幕样式编辑与自主密度设置

Windows 与 Mac 同步更新至 0.2.0。

- 设置新增「调整弹幕样式」：在同一弹窗调整每秒弹幕上限、字号、不透明度，以及导入 TTF / OTF 字体。
- 预览使用预设图片和 50 条示例文本；滑块变更实时显示，点击「保存样式」后应用到工作台预览和新建导出任务。关闭弹窗不保存草稿；已创建的导出任务保留原有样式。
- 字号档位为 0.4、0.6、0.8、1、1.5、2、2.5、3、3.5、4、4.5、5。默认 0.6 保持原有导出字号，不透明度默认 100%。
- 弹幕数量仅由用户设置的每秒上限控制。放大字号不会自动减少数量；轨道满时仍保留符合设置的弹幕和原始时间。高密度、大字号时可结合预览自行调整。
- 轨道随视频高度和字号计算，分散使用上下区域；优先选择不会遮挡、不会被后方长弹幕追上的位置，拥挤时使用细分位置减少同一行的堆叠。样式弹窗与导出共用排布、六秒生命周期及字体渲染，原始弹幕不删除。
- 同一时刻涌入的弹幕每条错开 10 毫秒，最多延后 0.5 秒入场；原始时间戳和结束时间保持不变，通过略微加快移动保持视频时长，不积累延后队列。普通分散到达的弹幕立即入场。
- 长素材的排布计算分批让出执行时间，支持取消，避免高密度弹幕排布阻塞录制或素材清理。
- 修复样式滑块拉满后末端多出一截的问题，移除输入框内边距并统一 Windows / Mac 的滑块外观。
- 预览按视频原始坐标缩放，减少设备窗口大小造成的字号差异。样式示例展示视觉规则，真实导出仍使用录制的弹幕内容和时间。

已进行源码回归、实际编码视频与样式预览对照，以及字体导入、手动保存和较小窗口验证。Windows 安装与升级检查由 GitHub Actions 完成；没有新增连续多日录制验收。

Mac 支持 Apple Silicon、macOS 14+，采用 ad-hoc 签名，尚未公证。已有应用内更新功能的用户可检查更新并安装；无需先卸载，录像和设置保留。
