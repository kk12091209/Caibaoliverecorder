# 0.3.5：弹幕文本编辑与天选记录

普通弹幕右键选择“编辑文本”，可修改这条弹幕的昵称和内容，并支持恢复原文。突出显示开启昵称前缀时使用修改后的“昵称：内容”。原始记录、UID 和同一用户的其他弹幕保留；列表、搜索、画面预览与弹幕版导出保持一致，排队导出保留提交时的文字。

B 站天选开奖作为礼物列表中的独立记录，固定署名“天选时刻”，在“仅显示礼物”中也会出现。默认展示参与口令，右键可编辑奖品备注；点击定位录像并查看中奖昵称和 UID。备注只影响这一条展示名称，不能改动中奖身份。

天选记录只用于查阅，始终不叠加到画面、不进入任何视频导出，也不受礼物导出开关影响。公开活动信息通过匿名请求采集，无需填写 Cookie；平台未公开的身份不推测补齐。名单未齐时显示待补全，错过采集且平台不再返回的历史轮次无法保证补回。中途首次发现已开奖活动时，标记首次发现结果的位置。

Windows 提供安装包、ZIP 与 7z；macOS 提供 Apple Silicon ZIP 与 DMG。升级保留本机素材和设置。macOS 安装包沿用现有 ad-hoc 签名方式，尚未公证。
