# v0.3.7 — 抖音礼物采集与录制切换恢复

Windows 与 Mac 同步更新至 0.3.7。

- 恢复独立的抖音 Cookie 管理，支持本机加密保存、重启读取、更新和清除，并补充从直播网页获取 Cookie 的指引。B 站登录信息独立保留。
- 抖音弹幕与礼物采集使用已保存的登录信息；更新 Cookie 后自动刷新采集连接，不打断正在写入的视频。平台实际下发的礼物可继续在列表、定位与画面展示中使用。
- 增加直播、连麦和 PK 切换时的录制保护：检测时间戳跳变、编码参数变化和画面进度停滞，保留已录内容后重新获取直播流，并在监控卡片显示恢复状态。
- 修复部分抖音连麦信息带特殊结尾时无法识别主播名牌的问题。

已实测抖音登录后的礼物采集，以及退出连麦恢复普通直播后的持续录制；重新进入连麦的真实场景仍待补充验证。异常恢复受网络与平台数据影响，可能有短暂空档，不承诺无缝补录。抖音福袋与中奖名单暂不记录。

Mac 包适用于 Apple Silicon、macOS 14 或更新版本，沿用临时签名，未经过 Apple 公证。Windows 需要 .NET Framework 4.7.2+ 与 WebView2。
