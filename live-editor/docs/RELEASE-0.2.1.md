# v0.2.1 — 弹幕速度、帧率与预览体验

Windows 与 Mac 同步更新至 0.2.1。

- 「调整弹幕样式」新增速度滑块：0.5～2.0 倍，步长 0.1，默认 1.0 倍，滑块两端保持正确对齐。
- 新增 30 / 60 帧选择，默认 60 帧；从 30 切换到 60 帧时提示处理可能变慢，并由用户确认。帧率改变滚动细腻程度，不改变滚动速度。30 帧的弹幕处理通常更快，实际耗时取决于素材、硬件与缓存。
- 调整速度或帧率后，样式预览完整滚动一轮，再恢复静态展示；新滚动画面就绪后直接接替当前画面，减少静态与滚动之间的闪烁。调整其他样式仍为静态预览。
- 点击「保存样式」后，速度、帧率与其他样式一起应用到主预览和新建导出；已创建的导出任务保留原设置，预处理缓存按设置区分，原始录像和弹幕保留。
- 修复数据恢复等提示无法关闭的问题：支持点击空白处、关闭按钮和 Esc；同一条恢复状态刷新后不会反复弹出。
- 未选择录像时显示小预览框；选中素材后放大，播放、暂停与定位保持尺寸。再次点击同一份素材取消选中并缩回，已保存选段保留。

## 安装与更新

- Windows 10 / 11 x64：中文安装包，另提供 ZIP / 7z 便携版；需要 .NET Framework 4.7.2+ 与 WebView2 Runtime。
- Mac：Apple Silicon、macOS 14+，提供 DMG 与 ZIP；沿用 ad-hoc 签名，尚未通过 Apple 公证，暂不支持 Intel Mac。
- 已有应用内更新功能的用户可检查更新，空闲时安装；无需先卸载，录像与设置保留。
- 本次不包含已导出成片再次编辑功能。

两端从同一提交构建，验证结果与安装包校验值见发布附件中的构建记录。自动检查不替代全部设备、显卡与连续多日直播验证。
